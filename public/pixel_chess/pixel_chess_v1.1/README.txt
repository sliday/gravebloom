# Technical #

	Assets are available as individual sprites and texture atlas
	Sprites use the .png file format with transparent background

	Each Asset		Pixel Resolution
	Top-Down Chess Piece	16x25 (Max Width/Max Height)
	Mini Chess Piece		10x12
	1-Bit Chess Piece	12x14
	Chess Tile		16x16
	Chess Board		160x160

To note:
	1. As with pixel art assets, it is recommended to use No Filter/Point Sampling and disabling anti-aliasing for assets to appear as intended in game engines, such as Unreal Engine, Unity, Godot, GameMaker, RPG Maker, Construct 3, Love2D, Phaser, MonoGame, GB Studio, and many others.
	2. When viewing and/or editing the Aseprite files, majority of the groups and their corresponding layers are set to Hide for the purpose that they overlap. Please Hide and Unhide the necessary group and layers for them to appear for you.
	3. For the texture_altas_pixel_chess.png every chess piece sprite (top-down, mini, and 1-bit) uses 32x32 spacing and the boards are 160x160 pixels in total pixel size each.
	4. For the top-down chess piece sprites, these have been exported with a canvas of 32x32 pixels to fit the top-down knight and its outline sprite fully. For this reason it may be advisable if using the top-down pieces with the chess boards, when aligning with the 16x16 chess tiles, to offset each piece by -8 pixels in the x-axis to have them appear center.
